# P4 — 디자인 시스템과 앱 셸

## 적용한 기반

WPF 앱에 아래의 재사용 가능한 리소스를 추가했다.

| 영역 | 파일 | 내용 |
| --- | --- | --- |
| 색상 | `Themes/Colors.xaml` | 캔버스·표면·테두리·텍스트·상태·브랜드 색상 |
| 컨트롤 | `Themes/Controls.xaml` | 버튼, 입력창, 카드, 상태 배지, 창 기본 스타일 |
| 셸 | `Views/MainWindow.xaml` | 상단 상태 바, 좌측 탐색, URL 입력 영역, 목록 빈 상태, 하단 작업 상태 |

## UX 원칙

1. 사용자가 가장 먼저 해야 할 일인 URL 추가를 메인 콘텐츠 상단에 둔다.
2. 작업 준비 상태와 향후 다운로드 상태가 항상 보이는 위치에 있다.
3. 목록 영역은 P5에서 가상화 목록으로 교체할 수 있도록 메인 콘텐츠 내부에 독립 배치했다.
4. 링크 추가·Chrome 탭·가져오기·설정은 현재 이관 단계가 표시되며, 아직 WinForms 기능을 모방해 실행하지 않는다.
5. 색상만으로 상태를 전달하지 않고 텍스트와 모양을 함께 사용한다.
