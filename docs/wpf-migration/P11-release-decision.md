# P11 — 배포 정책 및 전환 결정

결정일: 2026-08-21  
근거: [P10 동등성 및 배포 전 검증 보고서](P10-validation-report.md)

## 결정

| 배포 채널 | 현재 정책 | 실행 파일/설치 방식 |
| --- | --- | --- |
| 안정(Stable) | **계속 배포** | WinForms `GMTFV.exe`, `setup_winform.iss` 설치 프로그램 |
| WPF Preview | **제한 테스트용 설치 배포 허용** | `GMTFV.Wpf.exe`, 별도 AppId의 `setup_wpf.iss` 설치 프로그램 |
| WPF 기본 전환 | **보류** | 아래 전환 게이트가 모두 충족되고 수동 검증 기록이 있을 때만 결정 |

WinForms 프로젝트와 설치 프로그램은 유지한다. WPF 작업은 WinForms를 덮어쓰거나 기존 설치 경로·AppId·사용자 설정을 공유하지 않는다.

## WPF Preview 운영 원칙

1. Preview는 `GMTFV.Wpf.exe`라는 별도 실행 파일로 식별한다.
2. Preview를 테스트할 때에는 WinForms와 동시에 실행하지 않는다. 두 앱은 Chrome localhost 포트 `43128`과 PO Token 포트 `4416`을 경쟁할 수 있다.
3. WPF 설정은 `%LocalAppData%\GMTFV\wpf-settings.json`에만 기록한다. WinForms의 사용자 설정과 도구 설치 상태를 수정하지 않는다.
4. Preview 테스트에는 권한 있는 영상만 사용하고, 다운로드 결과·오류·도구 버전을 기록한다.
5. WPF 설치본은 이름에 Preview를 명시하고 제한 테스트 대상으로만 제공한다. 기본 다운로드나 자동 업데이트 대상으로 지정하지 않는다.

## WPF 기본 전환 게이트

아래 항목이 모두 충족되어야 P11 결정을 `전환 가능`으로 바꿀 수 있다.

- P10의 F02, F05, F14 미구현/부분 구현 항목을 해결한다.
- WinForms 설정 이전 또는 사용자가 명시적으로 선택하는 설정 가져오기 흐름을 제공한다.
- JSON 병렬 가져오기, 취소, 진행 상태를 WinForms 기준에 맞춘다.
- WPF 전용 설치 프로그램을 실제 컴파일하고 도구·Chrome 확장·라이선스 고지의 포함을 설치본에서 검증한다.
- P1 수동 검증 T01~T22를 실제 Windows 설치 환경에서 수행한다.
- 권한 있는 영상으로 영상/오디오/병합/취소/HTTP 403/자막/Chrome 탭 수신을 기록한다.
- 최소 1,000개 목록에서 스크롤·선택·진행 갱신 성능을 확인한다.
- 기존 WinForms 제거 없이 WPF Preview 설치·제거·롤백을 검증한다.

## 롤백 정책

- WPF Preview에 문제가 생기면 Preview 실행/배포만 중단하고, 기존 WinForms Stable 설치본을 계속 제공한다.
- WPF Preview 제거는 WinForms 설치 폴더와 WinForms 설정을 건드리지 않아야 한다.
- 사용자 설정 파일은 문제 분석을 위해 자동 삭제하지 않는다. 삭제 기능이 필요하면 사용자가 명시적으로 선택하는 별도 초기화 기능으로 제공한다.

## 다음 검토 시점

전환 게이트의 코드 보완과 실제 수동 검증 기록이 완료된 뒤 이 문서를 갱신한다. 그 전까지 WPF는 기본 다운로드 링크, 기존 설치 프로그램, 자동 업데이트 대상으로 지정하지 않는다.
