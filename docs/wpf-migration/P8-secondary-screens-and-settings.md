# P8 — 보조 화면과 설정

## 추가한 기능

| 영역 | 제공 기능 |
| --- | --- |
| 설정 | 저장 폴더, 영상/오디오 형식, 확장자, 파일명 형식, GPU, 오디오 비트레이트, 동시 다운로드 수를 WPF 사용자 설정 파일에 저장 |
| 목록 가져오기 | JSON/TXT를 읽어 URL을 순서대로 메타데이터 조회하고 목록에 추가 |
| 목록 내보내기 | JSON은 기존 `Url`, `IsTypeVideo`, `SubType`, `Quality`, `Fps` 필드를 유지하고, TXT는 URL만 기록 |
| 영상 상세 | 링크, 썸네일, 제목/채널/길이, 가능한 화질, 현재 상태 표시 및 링크 복사 |
| 자막 | 상세 창에서 자막 목록을 조회하고 선택한 자막을 SRT로 저장 |

## 설정 저장 위치

WPF 설정은 `%LocalAppData%\GMTFV\wpf-settings.json`에 저장한다. 실행 도구는 계속 설치/실행 폴더에서 읽기만 하며 AppData에 도구를 설치하지 않는다.

## 다운로드 반영

P7 다운로드는 저장된 폴더, 동시 실행 수, 영상/오디오 형식, 파일명 템플릿, GPU 인코더, 오디오 비트레이트를 다음 시작부터 사용한다. JSON으로 가져온 항목은 해당 파일에 저장된 형식과 화질을 항목별로 우선 적용한다.

## 남은 호환성 검증

기존 WinForms의 .NET 사용자 설정 파일을 WPF 설정 파일로 자동 이전하는 동작은 P10 호환성 검증 시 실제 설치 환경을 기준으로 추가 검증한다.
