# P1 — 수동 동등성 검증 목록

이 목록은 현재 WinForms를 기준으로 기록하며, P10에서 WPF 결과와 같은 조건으로 다시 실행한다. 실제 다운로드 검증에는 저작권 및 이용 권한이 있는 영상만 사용한다.

| ID | 시나리오 | 기대 결과 |
| --- | --- | --- |
| T01 | 앱을 도구가 포함된 배포 폴더에서 시작 | 기본 다운로드 경로, 도구 확인, 버전/상태 안내가 정상 표시된다. |
| T02 | 빈 목록에서 URL 추가 안내를 누름 | URL 추가 흐름이 시작된다. |
| T03 | 유효한 단일 YouTube URL 입력 | 임시 로딩 항목 후 제목·길이·썸네일이 표시된다. |
| T04 | 잘못된 URL 입력 | 목록이 손상되지 않고 이해 가능한 오류를 보인다. |
| T05 | 같은 영상 URL을 다시 입력 | 중복 또는 이미 추가 중임을 안내하고 항목을 중복 생성하지 않는다. |
| T06 | URL을 클립보드에 두고 `Ctrl+V` | YouTube URL이면 추가된다. |
| T07 | `Ctrl+N` 실행 | URL 추가 UI가 열린다. |
| T08 | URL/TXT/JSON 파일을 목록에 드래그 앤 드롭 | 유형에 맞는 추가 또는 가져오기 흐름이 시작된다. |
| T09 | JSON 목록 가져오기 | 진행 창이 보이고, 각 영상의 저장 설정이 보존된다. |
| T10 | 가져오기 중 일부 URL이 실패 | 나머지 영상은 계속 처리되고 완료/실패가 구분된다. |
| T11 | 목록을 JSON 및 TXT로 내보낸 뒤 다시 가져오기 | 영상 목록과 지원되는 설정이 복원된다. |
| T12 | 한 항목과 여러 항목을 선택해 삭제 | 의도한 항목만 삭제되고 빈 상태가 올바르게 나타난다. |
| T13 | 영상 상세에서 자막 목록을 조회 | 자막 언어/상태가 표시되고 선택한 자막을 저장할 수 있다. |
| T14 | 설정에서 저장 경로·형식·파일명·GPU·오디오·동시성을 변경 | 유효성 검사 후 저장되고 다음 다운로드에 반영된다. |
| T15 | 저장 경로가 없는/존재하지 않는 상황 | 명확한 안내와 안전한 선택 흐름을 제공한다. |
| T16 | 권한 있는 영상 2개 이상을 동시 다운로드 | 설정한 동시성 제한 안에서 큐가 동작하고 UI가 멈추지 않는다. |
| T17 | 영상+오디오 병합이 필요한 다운로드 | 영상·오디오·병합 단계와 병합 퍼센트가 표시된다. |
| T18 | 다운로드 오류 또는 HTTP 403 | 성공/실패 수와 항목별 진단 내용을 확인할 수 있다. |
| T19 | 다운로드 중 창 닫기를 시도 | 취소/종료 의도를 확인하고 외부 프로세스를 안전하게 정리한다. |
| T20 | Chrome 확장에서 YouTube 탭 URL 전송 | 수신한 개수가 안내되고 URL이 중복 없이 목록에 추가된다. |
| T21 | PO Token 공급자가 시작되지 않는 환경 | 앱이 비정상 종료하지 않고 가능한 안전한 다운로드 경로 또는 진단을 제공한다. |
| T22 | 긴 목록을 빠르게 스크롤 | 항목 선택·스크롤 위치·진행 갱신이 사용 가능하다. WPF에서는 P5 성능 기준으로 강화한다. |

## P10 비교 기록 규칙

- 각 테스트는 WinForms와 WPF에서 같은 입력, 같은 설정, 가능한 한 같은 네트워크 조건으로 실행한다.
- YouTube의 서버 응답 변화로 인한 결과는 기능 회귀와 분리해 기록한다. 명령줄/도구 버전/오류 원문도 남긴다.
- 기능 동등성은 단순 성공 여부뿐 아니라 진행 상태, 오류 안내, 종료 정리, 설정 보존까지 확인해야 한다.
