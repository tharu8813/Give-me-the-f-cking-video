# P7 — 다운로드·병합·진행률

## 구현 범위

- WPF 목록의 대기/실패 항목을 `yt-dlp` 큐로 실행한다.
- P8 설정 화면 전까지 기본 동시 실행 수는 1개이며, 출력 폴더는 `%UserProfile%\Downloads\GMTFV`이다.
- `yt-dlp.exe`, `ffmpeg.exe`, `pot-provider.exe`, bgutil PO Token 플러그인을 WPF 출력 폴더에 함께 복사한다.
- 다운로드 시작 시 localhost PO Token 공급자를 먼저 준비한다. 준비되지 않으면 PO Token이 필요 없는 YouTube 클라이언트로 안전하게 폴백한다.
- 진행 원문을 `DownloadProgress`로 변환해 항목과 전체 진행률에 반영한다.

## 단계와 퍼센트

| 단계 | 항목 표시 | 전체 퍼센트 기준 |
| --- | --- | --- |
| 영상/오디오 | yt-dlp 다운로드 퍼센트 | 0~89% |
| 병합 | FFmpeg `out_time_*` 분석 | 90~99% |
| 변환/마무리 | yt-dlp 후처리 메시지 | 98~99% |
| 완료 | 정상 종료 | 100% |

FFmpeg가 시간 정보를 제공하지 않으면 거짓 퍼센트를 만들지 않고 `영상과 오디오를 병합하는 중…` 상태로 남긴다.

## 안전성

- 취소 시 CancellationToken과 현재 활성 yt-dlp 프로세스 트리를 함께 종료한다.
- 창을 닫으면 실행 프로세스와 앱이 시작한 PO Token 공급자를 정리한다.
- HTTP 403, 비공개 영상, 외부 도구 누락은 항목별 실패 상태와 원인으로 남긴다.
- 실제 다운로드 검증은 사용 권한이 있는 영상으로 수행해야 한다.
