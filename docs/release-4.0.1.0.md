# GMTFV 4.0.1.0

## 주요 변경

- 도구 준비 상태를 기능별 한국어 안내로 정리하고, 설치 실패 원인·재시도·취소·검증 캐시를 보강했습니다.
- **원본 오디오 (변환 없음)**를 추가했습니다. 실제 코덱과 컨테이너에 따라 원본 보존·Stream Copy·변환을 결정하고 비트레이트 적용 범위를 명확하게 표시합니다.
- 작은 창에서 저장 경로를 읽을 수 있도록 옵션 배치를 개선했습니다. 목록 선택 시 화면이 밀리지 않으며, 설정을 닫으면 원래 조작하던 위치로 키보드 포커스가 돌아갑니다.
- 비활성 옵션의 설명을 확인할 수 있고, 실패가 없으면 빨간 경고를 표시하지 않습니다. 오류 창은 재시도 행동을 강조합니다.
- 긴 프로세스 출력, 완료 파일 검증, 목록 저장·취소, 종료 시 작업 정리를 보강했습니다.

## 다운로드

- `GMTFV-4.0.1.0-setup.exe`: Windows x64 설치본.
- `GMTFV-4.0.1.0-win-x64.zip`: 새 폴더에 모두 푼 뒤 `GMTFV.Wpf.exe` 실행.
- `GMTFV-4.0.1.0-SHA256SUMS.txt`: 설치본과 ZIP의 SHA-256.

Windows 10/11 x64용이며 .NET 10 Desktop Runtime을 포함합니다. 영상 다운로드에 사용하는 외부 도구는 앱의 **도구 및 진단**에서 별도로 준비합니다. 기존 WPF 설정·도구·다운로드 경로와 설치 식별자를 유지합니다.

공식 릴리즈는 [GitHub 4.0.1.0 페이지](https://github.com/tharu8813/Give-me-the-f-cking-video/releases/tag/4.0.1.0)에서 확인합니다. 자동 업데이트는 최신 정식 릴리즈의 정확한 설치 파일명·크기·SHA-256을 검증합니다.

## 검증 범위

Release 솔루션 빌드, WPF 255개 검사, Core/엔진 116개 검사를 통과했습니다. 900·1050·1220px 창 배치와 키보드 포커스, 선택 시 목록 위치 유지, 1,000개 항목 가상화를 확인했습니다. 상세 내용은 [UI/UX 점검](ui-ux-review.md)과 [안정성 검증 기록](stability-4.0.1.0.md)을 참고하세요.

최종 자체 포함 배포 폴더의 WPF/Core/Engine DLL을 검사 호스트에 복사하고 해시가 같은지 확인한 뒤, 해당 바이너리로 WPF 255개·엔진 116개 검사를 다시 통과했습니다. 별도 임의 AppId와 프로젝트 내부 테스트 폴더에서 4.0.0.0 설치 → 4.0.1.0 업그레이드 → 제거를 실행해 버전·설치 DLL 해시·사용자 파일 보존·런타임/라이선스를 확인했습니다.
