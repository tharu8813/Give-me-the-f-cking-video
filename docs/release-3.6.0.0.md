# GMTFV 3.6.0.0

WinForms를 공식 UI로 유지하고 다운로드 실행·취소·복구 및 완료 파일 검증을 정리한 안정화 릴리스입니다. WPF Preview는 이번 릴리스에서 제공하지 않습니다.

## 주요 변경

- 메타데이터·자막·다운로드가 공통 엔진과 프로세스 실행 경로를 사용합니다.
- 작업 취소 시 해당 작업의 자식 프로세스까지 종료하고, 오류 종류에 따라 제한된 재시도와 CPU 변환 복구를 적용합니다.
- 실제 완료 파일의 위치·컨테이너를 검증하고, 같은 이름의 기존 파일은 번호를 붙여 보존합니다.
- 여러 URL 입력, 정규화된 중복 감지, 실패 항목 재시도, 선택 작업 취소와 다운로드 중 URL 대기를 지원합니다.
- 요청 화질 범위와 FPS 선택, 목록 설정 복원 및 진단 로그 마스킹을 개선했습니다.
- 호환되지 않는 구버전 Deno를 발견했을 때 검증된 로컬 버전 설치 대상으로 처리하도록 수정했습니다.
- 최신 WinForms 프로젝트 배치·Designer UI·Chrome 확장·병렬 목록 가져오기를 유지하고 WPF 전용 프로젝트와 설치본을 제거했습니다.
- 설치 프로그램이 앱 폴더 전체를 삭제하거나 기존 제거 프로그램을 강제 실행하던 동작을 제거했습니다.

## 설치 및 업데이트

`GMTFV-3.6.0.0-setup.exe`를 실행하세요. 기존 GMTFV의 설치 경로와 AppId를 유지하며 기존 설정 형식을 사용합니다. Windows 10/11 x64, .NET Framework 4.7.2 이상과 인터넷 연결이 필요합니다.

이번 설치본에는 앱·관리 라이브러리·Chrome 확장·라이선스 고지가 포함됩니다. **yt-dlp, FFmpeg/ffprobe, Deno는 설치본에 번들하지 않고 첫 실행 시 `%AppData%/GMTFV`에 별도로 준비합니다.** 따라서 이전 설치본보다 크기가 작으며 최초 실행 때 도구 다운로드가 필요할 수 있습니다. 별도 PO Token 공급자 서버는 자동으로 실행하지 않습니다.

Chrome 확장을 사용 중이라면 확장 폴더를 확인하고 `chrome://extensions/`에서 다시 로드하세요. 실패·취소한 작업의 `.gmtfv-*` 임시 폴더는 파일 보존을 위해 남겨둡니다.

설치 파일의 SHA-256은 함께 배포하는 `SHA256SUMS.txt`에서 확인할 수 있습니다.

## 검증 범위

- Release 빌드: 경고 0, 오류 0
- Release 자동 테스트: 91개 통과
- 기반 안정화 엔진: 실제 yt-dlp·FFmpeg로 로컬 미디어 영상 6개·오디오 7개 형식 통과
- Inno Setup 설치본 컴파일 및 앱·설치본 버전 확인

실제 YouTube 다운로드 성공률, GPU 하드웨어, Chrome 브라우저 E2E 및 실제 설치·업그레이드·제거는 검증하지 않았습니다. 자세한 안정화 검증 범위는 [보고서](https://github.com/tharu8813/Give-me-the-f-cking-video/blob/3.6.0.0/docs/stabilization-report.md)를 참고하세요.
