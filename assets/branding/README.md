# GMTFV app icon

A download arrow with a play-shaped cutout: video + save in one silhouette.
Apricot `#E8AF84` and ink `#171716` match the WPF workspace palette.

- `app-icon.svg`: editable, flat vector master; transparent outside the tile.
- `app-icon.png`: 1024 px export for documentation and previews.
- `app-icon.ico`: 16, 20, 24, 32, 40, 48, 64, 96, 128 and 256 px Windows images.

The initial concept was generated with the built-in ImageGen tool, then rebuilt
as precise vector geometry for uniform colors and clean small-size rendering.
The WPF application, Windows executable, installer and project README use this icon.

Concept prompt: A minimal flat Windows app icon for a video downloader. One warm
apricot rounded square, a bold near-black downward download arrow, and a right-facing
play triangle cut out of its stem. Two solid colors, transparent corners, generous
spacing, recognizable at 16 px. No text, tray, gradients, shadows, texture or 3D.
